# Seatkey — дистрибутивы

Здесь лежат сборки Seatkey — локального OpenAI-совместимого
шлюза поверх CLI-агентов с подпиской. Your seat is your key.

Код закрыт, дистрибутивы — нет: приложение проверяет обновления здесь,
анонимно и без токена.

## Скачать

**[Последний релиз](../../releases/latest)**

| Платформа | Файл |
|---|---|
| macOS, Apple Silicon | `Seatkey-<версия>-arm64.dmg` |
| macOS, Intel | `Seatkey-<версия>.dmg` |
| Windows | `Seatkey Setup <версия>.exe` |
| Linux | `Seatkey-<версия>.AppImage`, `.deb` |

Файлы `-mac.zip` и `.blockmap` качать не нужно: их берёт автообновление.

## Первый запуск

Сборки подписаны самодельным сертификатом, а не Apple Developer ID.
Gatekeeper такой сертификат не признаёт, поэтому **один раз** при первой
установке приложение придётся открыть вручную:

- **macOS 15 и новее** — Системные настройки → «Конфиденциальность
  и безопасность», пролистать вниз, «Всё равно открыть»;
- **macOS 14 и старше** — правый клик по значку → «Открыть» → «Открыть».

Начиная с macOS 15 правый клик Gatekeeper больше не обходит — Apple убрала
этот путь.

## Обновления

Приложение проверяет их само и показывает в **Settings → App**. Обновление
скачивается в фоне и ставится по кнопке — установку Seatkey никогда не
начинает сам: он держит локальный сервер, и перезапуск оборвал бы запросы
подключённых приложений.

Повторно снимать карантин не нужно: обновление приходит подписанным тем же
сертификатом, и система считает его тем же приложением.
