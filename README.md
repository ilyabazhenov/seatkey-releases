# Seatkey — дистрибутивы

Здесь лежат сборки Seatkey — локального OpenAI-совместимого
шлюза поверх CLI-агентов с подпиской. Your seat is your key.

Код закрыт, дистрибутивы — нет: приложение проверяет обновления здесь,
анонимно и без токена.

## Скачать

**[Последний релиз](../../releases/latest)**

| Платформа | Файл |
|---|---|
| macOS, Apple Silicon | `Seatkey-<версия>-arm64.dmg` |
| macOS, Intel | `Seatkey-<версия>.dmg` |
| Windows | `Seatkey Setup <версия>.exe` |
| Linux | `Seatkey-<версия>.AppImage`, `.deb` |

## Первый запуск

Сборки не подписаны. На macOS система откажется открыть приложение
двойным щелчком: правый клик по значку → «Открыть» → «Открыть» ещё раз.
Дальше приложение запускается как обычно.

## Обновления

В самом приложении: **Settings → App → «Проверить обновления»**.
На Windows и Linux обновление скачивается в фоне и ставится по кнопке;
на macOS пока открывается ссылка на .dmg — автоустановка требует подписи
Developer ID.
